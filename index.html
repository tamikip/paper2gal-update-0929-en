SIDE-BY-SIDE READING

While playing, open “Read Along” from the bottom toolbar to view a local PDF. On wide screens, place it beside the game and drag the divider to adjust each side's width.

READER CONTROLS

Scroll continuously, select text, and zoom with Ctrl + mouse wheel.

Search highlights matches, shows a result count, and jumps to the previous or next result. In the reader, Ctrl + F focuses search; Enter and Shift + Enter move between matches.

STORY PLAYBACK

Opening the reader turns off story autoplay so you can check the source. After loading a save, you can select the local PDF again.

SMALLER SETTINGS FILES

Custom music is now saved in separate files on your device. Settings store only references so music data no longer makes the configuration file too large.

ACTION REQUIRED

Custom music imported in an older version will not migrate automatically. Please import it again after updating.
